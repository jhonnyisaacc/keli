## Novelty boundary

Overlap is not evidence of independent invention. Establishing priority would require commit ancestry and author history beyond this spike. Raw logs, lexical search, bounded memory, verification and skill indexes already have runtime counterparts. The potentially new combinations for this baseline are executable persistent context, bidirectional phase-memory coupling, learned composition and prediction-error learning. They remain candidates, not accepted features.
