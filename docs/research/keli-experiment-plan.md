# Fast spike experiment plan

Frozen before benchmark execution. No production integration. All adapters live under `experiments/2026-fast-spike`; results and complete fixture traces under `docs/evidence/2026-fast-spike`. Temporary databases and generated repositories must live beneath a harness-created temporary KELI_STATE_DIR. No paid model calls, production chat archives, external writes or reference-repo patches.

This fast spike tests architectural primitives and local failure modes. It cannot complete paper-scale or live-model evaluation. Scripted policies are labeled as such; a fixture oracle never counts as evidence of model intelligence. No production feature is accepted on these micro-tests alone.

## Coverage and measurements

A: long histories, exact nonce, eviction/restart. B: raw multi-session notes, time, repeated sessions, paraphrase, expansion at session boundaries. C: multi-phase misleading hypothesis, deterministic/transient failures, revision reset. D: early commitments, implicit lexical mismatch, current revision and other-project constraints. E: unfamiliar environment, repeated prediction error, transient and cross-repo pollution. F: misleading root test command versus package metadata, easy-task exploration overhead. G/H: useful/distracting/dependency/outdated/procedural skill cases. I: missing input, ambiguous intent, conflicting or partial tool evidence. J: empty artifact, false claim, focused-pass/integration-fail, stale generated output, unexpected dirty file, correct implementation.

Each experiment emits JSONL observations and a JSON summary. Metrics schema includes task success, independently verified success, false completion, repeated actions/failed hypotheses, replans/useful replans, calls, tokens, context growth, latency, precision/recall, writes/usefulness/staleness and human intervention. Undefined metrics are null with a reason, not invented zeroes. Tokens are null without a model tokenizer/request; bytes are measured separately. Human intervention is a required policy response in some fixtures, not an observed live human outcome. Wall time is measured single-host microbenchmark time, not model latency. No aggregate agent-success leaderboard across dissimilar fixture types.
